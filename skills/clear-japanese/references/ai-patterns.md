# AIっぽく読める癖と語彙のカタログ

この資料の範囲は、AIの文に出やすい形の索引と、見直したい語彙・構文のカタログである。前半の索引は nihongo（MIT）を元にし、後半のカタログは yomiyasu（MIT）を元にしている。`scripts/yomiyasu_lint.py` が出す指摘は、このカタログの語と形に対応する。リンターは、太字の頻度と箇条書きの比率も報告する。太字の頻度の目安は `technical-writing.md` に従う。箇条書きの比率は参考値として読み、比率を下げるためだけに箇条書きを地の文へ直さない。箇条書きは独立した項目に使い、因果や経緯は文でつなぐ、という決まりで判断する。

## 癖の索引

書いた後に探す。場に合っていれば残してよい。人の文にも普通にある言い方（最後に、まさに）は癖に数えない。1つの癖だけで「AIが書いた」と決めない。

- 始め方（直し方は `rewrite-rules.md` の「セルフラベリングと否定対比の整理」）：「結論から言うと」「重要なのは」「ポイントは」、「以下にまとめます」「次のとおりです」のような予告、「〜と思ったことはありませんか」、相手を持ち上げる文（いい質問ですね）。
- 終わり方：「参考になれば幸いです」「ぜひ試してみてください」「今後が期待されます」、段落の最後に足す意味づけ（これは〜を示しています）、決め台詞。
- 型：「XではなくY」「単なるXではない」（誤解を正す時だけ残す）、「〜だけでなく〜も」、3つにそろえた列挙、「一番大きいのは〜です」のような分裂文。
- 記号（直し方は `orthography.md` と `rewrite-rules.md` の「装飾記号と不要な空白の排除」）：全角ダッシュ、文中のラベル（結論：）、強調のための鍵括弧、補足の丸括弧の多用、飾りの絵文字、太字の多用。値のラベル（日時：）は残す。
- 保険：「一概には言えませんが」「場合によっては」を重ねる。保険は1つまで。
- 言葉（直し方は `craft.md` の「言葉の選び方」と、下の語彙カタログ）：定義していない造語（信頼の複利）、和語の造語（確かめ、直し）、技術の比喩（静かに壊れる、地味に効く）、「この学び」「現代の私たちは」。
- 足しすぎ：頼まれていない解説、別案、追加の質問、していないことの列挙。
- そろいすぎ：どの段落も同じ組み立て、どの項目も同じ長さ、どの文も同じ長さ。直し方は `craft.md` の「そろいすぎの点検」にある。
- 整いすぎ：人なら省く所まで説明する、短いメールの敬語を1段上げる、エッセイで筋書きを順に説明する、直前の文を言い直してつなぐ、無難な感想でまとめる、「さて、本題です」と切り替える。

直す時は、癖の言葉だけを別の言葉に替えない。何を言いたい文かに戻って書き直す。

## 語彙と構文のカタログ

このカタログは、AI生成文で見直したい言葉や構文と、言い換えの候補をまとめている。候補は、原文と文脈で同じ意味になる場合だけ使う。語があることだけでは誤りとしない。

### 1. 比喩的に使われる動詞

出来事や技術的な操作を不自然な比喩で表している場合は、比喩が指す中身が原文と文脈から1つに決まるときだけ、文脈に合うふだんの言葉に直す。1つに決まらないときは、原文の言い方を残し、分かりにくければ言い換えずに補足を足すか、書き手に確かめる（`rewrite-rules.md` の「比喩動詞の具体化」）。新しく書く文には、この表の比喩を使わない。
なお、「骨が折れる」「手を焼く」「目から鱗が落ちる」「首を長くして待つ」のような、ふだんの日本語で定着した慣用句は、AIっぽい比喩として扱わず、そのまま残す。業務仕様でも、意味を取り違えるおそれがなければ残す。迷ったときの目安は、その言い方を、AIが広まる前の人の文章でもふつうに見かけるかどうかである。見かけるなら残す。

| 動詞 | 見直したい用例 | 言い換えの候補と注意点 |
|---|---|---|
| **効く / 効いてくる** | 「地味に効きます」「〜が効いてくる」 | 「目立たないながらも役に立つ」「じわじわ助けになる」（「地味に」の含みを残す） |
| **壊れる** | 「データが静かに壊れる」「設計が壊れる」 | データやシステムに対する「壊れる」は、「おかしくなる」「使えなくなる」のように同じ広さの意味を持つ言葉にする。「データの整合性が失われる」「不整合が生じる」と書くのは、元の文や前後から整合性の話だと明らかなときだけに限定し、言い切りの強さも保つ。時計や機械、身体など文字どおりの「壊れる」はそのまま残す。 |
| **倒す** | 「〜側に倒す」「残さない側に倒す」 | 「〜を優先する」「〜の扱いに統一する」「除外する」 |
| **溶かす** | 「時間を溶かしました」 | 「時間がかかってしまった」「時間を費やしてしまった」（無駄にした・かかってしまったという後悔の含みを残す） |
| **潰す** | 「1つずつ潰していく」 | 「1つずつ直す」「消す」「解決する」 |
| **踏み込む** | 「〜まで踏み込んで」 | 「詳しく調べる」「掘り下げる」 |
| **引き返す** | 「動かしながら引き返す」 | 「元の状態に戻す」 |
| **添える** | 「経路が代わりに添える」 | 「渡す」「つける」 |
| **収斂する** | 「その価格帯に収斂した」 | 「落ち着いた」「決まった」 |
| **沈黙する** | 「静かに沈黙する」 | 「反応しない」「応答しない」。終了したか、通知が出たかは、原文や文脈から分かる場合だけ書く。 |
| **黙って** | 「黙って無視される」「黙って捨てられる」 | 「気づかないうちに無視される」「知らないうちに破棄される」（仕組みとしてエラーや通知が出ないことがはっきり分かる場合に限り「エラーを出さずに」「通知なく」とする） |


### 2. 英語を直訳したような構文

英語を直訳したような不自然な構文を、意味を保って自然な日本語に直す。

| 英語の原表現 | AIの直訳日本語 | 自然な日本語 |
|---|---|---|
| *silently fail / ignored* | 「静かに壊れる」「黙って無視される」 | 「気づかないうちにデータがおかしくなる」「知らないうちに無視される」（データ等への「壊れる」は「おかしくなる」「使えなくなる」のように同等の広さの言葉にし、整合性の文脈であることが明らかな場合のみ「整合性が失われる」等とする。「静かに」「黙って」のぼかしは気づけない幅のまま直す。「通知なく」「エラーを出さずに」のように仕組みの話にするのは、元の文や前後から明らかな場合のみ） |
| *the moment ...* | 「〜した瞬間」「〜した瞬間に」 | 「〜するとすぐに」「〜した時点で」 |
| *single source of truth* | 「〜を正本にする」「〜の正本として」 | 原文や比較の基準、参照元など、その語が指す役割に合う言葉で書く。唯一の参照元と明示されている場合は、その限定を保つ。信頼性・唯一性・更新元という役割を新たに足さず、正式な文書を区別する「正本」は意味を保って残す。 |
| *point to / suggest* | 「〜を指している」「〜を示唆している」 | 「〜を表している」「〜と考えられる」「〜を意味する」。言い切りと推量の強さを保って選ぶ。 |
| *load-bearing* | 「耐力のある」「構造を支える」 | 「不可欠な」「欠かせない」「外せない」 |
| *it is not X, it is Y* | 「Xではなく、Yです」 | 単なる修辞でXを削っても通じる場合は「Yです」とする。Xと誤解されやすい点への反論や見方の切り替えを担っている場合は、否定を残して「Xではなく、Yです」と自然に整える（Aに加えてBなどに改変しない。「そのもの」等の余計な強調語は足さない）。 |
| *delve into* | 「〜に深く分け入る」「深掘りする」 | 「詳しく調べる」「具体的に見ていく」 |
| *em dash (— / ―)* | 「〜――とりわけ〜――は」 | 「〜、特に〜は」のように、対象と強調する範囲を保って句読点や助詞でつなぐ。 |


### 3. 2026年急増語（Qiita 7万件調査に基づく分類）

調査で増加が見られた語のうち、比喩や飾りとして使われているものだけを見直す。文字どおりの意味で使われている語は変えない。「実測」「照合」「既定」「要点」「断定」は、技術文書や仕事の文書でふだん使う漢語であり、実際に測った値、実際の照合、設定の既定値を指しているときはそのまま残す（`craft.md` の「言葉の選び方」）。言い換えの候補は、比喩として使われ、かつ候補と同じ意味になる場合だけ使う。

| 分類 | 増加した語 | 用例 | 言い換えの候補 |
|---|---|---|---|
| **障害・失敗の比喩** | `事故` `混ざる` `落とし穴` `破綻` `実害` `素通り` | 「〜という事故」「落とし穴があります」 | `事故`→「思いがけない失敗・トラブル」、`混ざる`→「入り込む」、`落とし穴`→「見落としやすい点・気をつけたい点」、`破綻`→「うまくいかなくなる」、`実害`→「実際の困りごと」、`素通り`→「気づかず通る」 |
| **確認・検証の比喩** | `実測` `疑う` `照合` `突き合わせる` `断定` `取り違える` | 「実測では」「〜を取り違えると」 | `実測`→「実際に測った値」、`疑う`→「念のため見直す・確かめる」、`照合`→「照らし合わせる」、`突き合わせる`→「見比べる・比べる」、`断定`→「言い切る」、`取り違える`→「順序を間違える・勘違いする」 |
| **役割・位置の比喩** | `入口` `土台` `道具` `核心` `主役` `構図` `線引き` | 「〜の入口として」「〜するための土台」 | `入口`→「はじめの一歩・手始め」、`土台`→「基本・根っこ」、`道具`→「手段・やり方」、`核心`→「いちばん肝心なところ・大事な点」、`主役`→「中心」、`構図`→「全体の仕組み・関係」、`線引き`→「区切り・境界」 |
| **評価・結論の定型** | `既定` `別物` `定番` `要点` `定石` `桁違い` | 「既定では」「〜とは別物です」 | `既定`→「初めの設定・もともとの設定」、`別物`→「まったく違うもの」、`定番`→「よく使われるもの」、`要点`→「大事なところ」、`定石`→「いつものやり方・標準の進め方」、`桁違い`→「段違い・はるかに大きい」 |


### 4. 体験を大げさに見せる熟語

個人のささやかな体験や日常的な技術判断を、難しい熟語で大げさに語らない。書き手が意図して使っている誇張や強調（大幅に、劇的に、全力で）と、気持ちの言葉は、この節の対象ではないので残す。

| 見直したい熟語 | 大げさな表現の例 | 自然な表現 |
|---|---|---|
| `真理` `真実` `結末` `宿命` `運命` `境地` `極致` `究極` `虚飾` `虚像` `美学` `深淵` `禁欲的` `優美` `冷徹` `残酷` `凝縮` `結晶` | 日常の喧騒という虚飾を剥ぎ取った時、この道具の真実が見えてくる。 | 日々の忙しさから離れたとき、この道具の本当の良さが見えてくる。 |

日常や業務の体験に、元にない固有名詞や大きな教訓を足さない。


### 5. 具体的に見えて意味が曖昧な言葉

具体的に見えても、何を指すか分からない言葉を見直す。

語だけで判定せず、何を指すかを原文と提供文脈から確かめる。本文だけでなく、変更理由や確認事項でも同じ基準を使う。

| 分類 | 見直したい語 | 書き直すときの注意点 |
|---|---|---|
| **質感を装う語** | `手触り` `肌感` `肌感覚` `体温` `温度感` `熱量` `血の通った` `泥臭い` | 元の文や前後から分かる範囲で客観的な事実を書く。情報が足りない場合は作り話を足さず、同じ幅のふだんの言葉で書く。 |
| **理解を曖昧に表す語** | `解像度`（解像度を上げる/高い） `腹落ち` `メンタルモデル` `文脈` | その語が指す考えや前提を、元の文にある情報の範囲で説明する。定義された用語や、意味が明確な「文脈」などは残す。 |
| **評価を装う語** | `本質` `本質的` `地に足のついた` `等身大` | 「本質的なアプローチ」のような空疎な修飾語は削る。ただし、文の主題や論点そのものになっている語（「本質」「核心」など）を「目的」など別の概念へすり替えたり、勝手に動詞を足して文の働きを変えてはならない（「いちばん肝心な点」「大事なところ」など平易な言葉にするか、そのまま残す）。 |
| **未定義造語** | `意思決定OS` などの勝手な比喩命名 | ふだん使う平易な言葉や客観的な機能説明で書く（硬い漢語を並べない）。 |
| **役割を大げさに呼ぶ語** | ルールを指す `契約`、原文や比較の基準を指す `正本` | 「ルール」「方針」「原文」「比較の基準」「参照するファイル」等、実際の役割に合う語へ直す。取引・合意としての契約、正式な文書を区別する正本、定義された専門用語の意味は保つ。 |
| **指す内容が曖昧な名詞** | 手段や書き方を曖昧に呼ぶ `仕組み` | 何を行うか、何を指すかが分かる範囲で書く。実際の処理の関係や動作を説明する「仕組み」は残す。具体的に見せるために数値・体験・原因を足したり、評価や推量を消したりしない。 |


### 6. 不要な前置きと定型の結び

意味を担わない前置きや定型の結びを削る。意見文、エッセイ、記事の結論は、まとめではなく主張なので消さない。

| 分類 | 見直したい表現 | 書き直すときの注意点 |
|---|---|---|
| **前置フィラー** | `重要なのは` `結論から言うと` `正直に言うと` `避けたいのは` `ここで注目すべきは` | 単なる前置きは削る。評価は述語へ移して保つ。理由・対比・結論や文の働きの切替を示す場合は、その関係を残す。比較から採用方針へ移る「結論として」などを、語だけで不要と判定しない。 |
| **文末の付け足し** | `〜というわけです` `〜に他なりません` `〜と言えるでしょう` `面白いのはここです` | 原文の説明・評価・推量を、その働きと強さを保って書く。文末をそろえるために評価を事実へ変えたり、推量を断定へ上げたりしない。 |
| **定型の結び** | `いかがでしたでしょうか` `ぜひ試してみてください` `〜の参考になれば幸いです` | 意味を担わない定型の呼びかけを削り、本文の自然な結びで終わる。 |
