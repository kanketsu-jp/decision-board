# 要約・まとめ

## 手順

1. 原文の目的と読み手を1文で確かめます。
2. 原文から「結論・根拠・条件・数値・期限・未決事項」を抜き出します。抜き出す言葉は原文のままにします。
3. 重要度の順に並べ、指定された長さに合わせて下から削ります。
4. 原本 §1 の規則で文を整えます。
5. 原文に無いことを足していないか、条件（「〜の場合のみ」「〜を除く」）と数値（単位・時点）を落としていないかを点検します。

要約・簡潔にする場合も、「意味の保持」と「情報の不増補（足さないこと）」を最優先にします。要約で事実を作らず、数値を丸めて変えず、条件を落としません。

## 長さ

「要約して」「まとめて」に長さの指定があれば、その指定に合わせます。指定がなければ、原文の2〜3割、または箇条書き3〜7項目を目安にします。

「簡潔に」は、原文とほぼ同じ順序を保ちながら、原文より短くします。目安は原文の6〜7割です。

## 「まとめて」の型

結論を1行にします。続けて要点を箇条書きにします。未決事項や次の一手があれば、その後に置きます。見出しは要らなければ付けません。

## 「簡潔に」の削り方

前置き・繰り返し・言い換え・自己言及（「本稿では」など）・不要な否定対比を削ります。主語と述語の関係・条件・数値は削りません。

## 出力

本文を示した後、末尾に「削ったもの」を1〜3行で示します。何を落としたかを書き、落としたものが無ければ「削ったもの」は書きません。要約と簡潔の出力に推敲の出力項目を混ぜません。

点検に使えるときは、次のように `scripts/yomiyasu_diff.py` を使います。

```bash
python3 <この SKILL.md のあるディレクトリ>/scripts/yomiyasu_diff.py 元の文.txt 書き直した文.txt --stance=<勧め|決まり|説明>
```
