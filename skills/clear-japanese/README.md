# clear-japanese

clear-japanese は、日本語の文章を書く・直す・短くする・要約するための Claude Code の Skill です。相手・目的・媒体に合う言い方を選び、すでにある文章は意味と条件を保ったまま直します。

この Skill は yomiyasu（MIT）と nihongo（MIT）を元にしています。

## 禁止用途

詐欺、フィッシング、なりすまし、相手を騙すための文には使わないでください。実在の組織や人を装う文、偽のログインや支払いへ誘う文、パスワードや暗証番号を聞き出す文は、頼まれても書かず、直さない決まりにしています。

## 呼び出し方

依頼の言葉で、Skill がする作業が決まります。Claude Code では `/clear-japanese` と送って呼び出すこともできます。

| 頼み方 | Skill がすること |
|---|---|
| 「綺麗な日本語で」「わかりやすく」「読みやすくして」「AIっぽさをなくして」 | 文章を直します。長さは原文とほぼ同じです |
| 「簡潔に」 | 意味・条件・数値を残して短くします。目安は原文の6〜7割です |
| 「要約して」「まとめて」 | 要約します。長さの指定が無ければ、原文の2〜3割か、箇条書き3〜7項目にします |
| 「メールを書いて」「お知らせを作って」など | メール、お知らせ、資料、UI 文言、技術文書などを新しく書きます |
| 自分の文を貼って「私の書き方を覚えて」 | 一人称・文末・敬語の高さなどをまとめた書き方メモを作ります |

直した文は、「書き直した本文」「変えたところ」の順で返します。意味や重みを担っているために残した前置きがあれば「残したAIっぽいところ」に、本文を確定するために確認が要ることがあれば「書き手に確かめたい点」に書きます。

## 短い版と詳しい版

| | 短い版 | 詳しい版 |
|---|---|---|
| ファイル | `ALWAYS.md` | `SKILL.md` と `references/` |
| 使う場面 | 普段の返事、雑談、短い質問 | メール、お知らせ、ES、資料、README、UI 文言、推敲、要約 |
| 読み込まれ方 | 設定に登録しておくと毎回 | 人に出す文章を書く時と直す時 |

短い版を使うには、Claude Code の設定ファイル（`~/.claude/CLAUDE.md`、またはプロジェクトの `CLAUDE.md`）に次の1行を足します。

```
@~/.claude/skills/clear-japanese/ALWAYS.md
```

## 使用例

次の文は、AI が書いた Slack の投稿です。

```
@channel お疲れさまです！

本日のデプロイについて共有させていただきます🚀

**結論**：本日18時のリリースは予定どおり実施します。

**背景**：昨日発見された決済画面の不具合は、すでに修正済みであり、ステージング環境での検証も完了しております。

**お願い**：18時〜18時30分の間は、本番環境への変更を控えていただけますと幸いです。

ご不明点等ございましたら、お気軽にスレッドにてお知らせください！引き続きよろしくお願いいたします🙏
```

直した後の文は次のとおりです。この例は取り込み元の nihongo の README にある例です。

```
@channel お疲れさまです！
本日18時のリリースは予定どおり実施します🚀

昨日見つかった決済画面の不具合は修正済みで、ステージング環境での検証も完了しています。

**18時〜18時30分は、本番環境への変更を控えてください。**

不明点があればスレッドでお知らせください。よろしくお願いします🙏
```

「結論：」「背景：」のようなラベルを外し、社内のチャットには重すぎる「させていただきます」「いただけますと幸いです」を、チームに向けた普通の言い方にしています。日時とお願いの中身は変えていません。

## スクリプト

`scripts/` に5本のスクリプトがあります。どれも Python の標準ライブラリだけで動きます。指摘は見直す候補であり、意味が変わったと決めつけるものではありません。

| スクリプト | 検査すること | 書き換えるか |
|---|---|---|
| `yomiyasu_lint.py` | 1つの文章の中の、見直したい語・比喩・前置き・記号・太字にならない書き方 | 書き換えません |
| `check_meaning.py` | 原文と直した文で、確かさ・強さ・程度・否定・数値と日時・中身の言葉が変わった箇所 | 書き換えません |
| `revert_broken.py` | `check_meaning.py` と同じ基準で候補が出た文を、原文の文に戻します | 出力ファイルに書きます |
| `yomiyasu_diff.py` | 原文と直した文で、文末の種類と立場、言い回しの増減、元にない語と消えた語 | 書き換えません |
| `trim_commas.py` | 短い文の頭の語句の後と「を」の後の、要らない読点 | 出力ファイルに書きます |

文章を直した後は、次の順に実行します。

```bash
python3 scripts/yomiyasu_lint.py 直した文.md
python3 scripts/revert_broken.py 原文.md 直した文.md 戻した文.md
python3 scripts/yomiyasu_diff.py 原文.md 戻した文.md --stance=説明
python3 scripts/trim_commas.py 戻した文.md 仕上げた文.md
```

`--stance` には、文書の立場を `勧め`・`決まり`・`説明` のどれかで指定します。伏せる・置き換えるよう頼まれた値がある時は、依頼文をファイルに保存して、`revert_broken.py` の末尾に `--request 依頼.md` を付けます。

## テスト

`tests/` に、`check_meaning.py`・`revert_broken.py`・`trim_commas.py` の回帰テストがあります。次のコマンドで全部を実行します。pytest は要りません。

```bash
python3 tests/run_all.py
```

`evaluations/` には、取り込み元の nihongo が版ごとに行った比較の記録と、その課題があります。yomiyasu と統合した後の clear-japanese では、同じ比較を測り直していません。

## 注意

AI が手順を読んで判断する作りなので、同じ依頼でも毎回同じ文になるとは限りません。数字、日付、固有名詞は、送る前に自分の目で確認してください。
