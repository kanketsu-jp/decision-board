# Lumen

Lumenは、現代の開発現場におけるログ分析の課題を解決するために生まれた、革新的なオープンソースのログビューアです。私たちは、開発者がより本質的な作業に集中できる世界を実現したいと考えています。Lumenを活用することで、大量のログの中から必要な情報を素早く見つけ出すことが可能となります。

なお、Lumenを動かすにはNode.js 20以上が必要となります（Node.js 18では起動しません）。また、環境変数 `LUMEN_SECRET` の設定が必須となっておりますので、ご注意ください。インストールは `npm install -g lumen-viewer` で行うことができ、`lumen start` を実行すると、デフォルトではポート3000番で起動いたします。ポートは `--port` オプションで変更することが可能です。
