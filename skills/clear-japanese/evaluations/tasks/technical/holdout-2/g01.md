# imgshrink

imgshrinkは、画像の容量削減という普遍的な課題に真正面から向き合うために開発された、次世代の画像圧縮CLIツールです。対応している形式はJPEGとPNGのみとなっており、WebPには現在対応しておりません。インストールには `brew install imgshrink` をご利用いただけます。`imgshrink photo.jpg` を実行すると、元のファイルは残したまま、同じフォルダに `photo.min.jpg` が作成されます。`--quality` オプションで画質を1〜100の範囲で指定することができ、指定しない場合は80が使用されます。
