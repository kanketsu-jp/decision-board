# tinyqueue-jp

tinyqueue-jpは、シンプルさと高いパフォーマンスを追求した、軽量な優先度付きキューの実装です。私たちは、すべての開発者にとって使いやすいデータ構造を提供することを使命としています。依存パッケージは一切なく、Python 3.10以上で動作いたします（3.9以下はサポート対象外となります）。インストールは `pip install tinyqueue-jp` で可能です。要素を追加するには `q.push(item, priority)` を、最も優先度の高い要素を取り出すには `q.pop()` を使用してください。なお、優先度は数値が小さいほど高いものとして扱われますので、ご注意ください。
