# 判断ボードの文面の規則

この規則は [yomiyasu](https://github.com/nanaism/yomiyasu)（MIT, nanaism）を、判断ボードで人間に判断を求める文専用に書き換えたものです。

## 最優先の規則

「意味の保持」と「情報の不増補」を、ほかのすべての規則より優先します。

- 意味の保持: 元の主張、比重、言い切りの強さ、文の働き（説明・評価・依頼・判断の問い）を変えません。
- 情報の不増補: 元の文にない理由、条件、数値、期限、効果、推薦を足しません。分からないことは分からないままにします。
- 文を短くするために、選択の条件や否定、例外、誰が何を決めるかを削りません。
- 元の文から判断を一つに確定できないときは、勝手に決めず、別の判断に分けるか確認事項にします。

## yomiyasu の7原則を判断の問いに使う

### 1. 非生物主語

道具や選択肢に意志や判断を持たせません。仕組みが実際に行う処理の説明は残します。

- 避ける例: 「この選択が品質を左右します」
- 問いにする例: 「この選択で、障害の報告が届くまでの時間が変わります」

「システムが望む」「設計が判断する」のような表現は、誰が選ぶのか、何が変わるのかを元の情報の範囲で書きます。主体や効果を推測して補いません。

### 2. 比喩動詞

技術的な判断を「倒す」「潰す」「溶かす」「踏み込む」「静かに壊れる」などで表さず、普段の動詞にします。

- 「案A側に倒しますか」→「案Aを優先しますか」
- 「未解決の点を潰しますか」→「未解決の点を解決しますか」
- 「この変更で時間を溶かしますか」→「この変更に時間を使いますか」

比喩が持つ評価や後悔の含みは残します。文字どおりの「機械が壊れる」や定着した慣用句は、意味を変えない限り直しません。

### 3. 名詞連続

名詞を重ねて判断対象を隠しません。誰が何を決めるのか、選ぶと何が変わるのかを動作で書きます。

- 避ける例: 「障害対応時間短縮方針を決定しますか」
- 問いにする例: 「障害対応にかかる時間を短くする方針を決めますか」

ただし、仕様で定義された用語や選択肢の正式な名称は、勝手に言い換えません。

### 4. 装飾

絵文字、意味のない強調、コピー調の短い句、不要な前置きや定型の結びを足しません。見出しと本文は、判断に必要な情報から始めます。

- 避ける例: 「重要なのは、最高の案を選ぶことです！」
- 問いにする例: 「どの案を採るか決めますか」

「結論から言うと」「ぜひ確認してください」のような前置きは、理由や依頼の働きを持たない場合に削ります。評価や対比を担う場合は、その意味を残します。

### 5. 否定対比

「AではなくB」が誤解の訂正や見方の切り替えを担うなら残します。単なる飾りなら短くします。否定を「Aに加えてB」に変えて、選択の比重を変えてはいけません。

- 比重を保つ例: 「速度ではなく、復旧時間を優先しますか」
- 飾りを削る例: 「これは単なる確認ではなく、判断です」→「これは判断です」

元の文がどちらを退けているか分からない場合は、肯定文へ決め打ちしません。

### 6. 記号

句読点、かっこ、コロン、ダッシュ、Markdown の強調は、意味がある範囲で使います。記号で重要さを演出しません。Markdown の太字は、太字として表示される形にします。

- 避ける例: 「この案を選ぶ――それが最善です」
- 問いにする例: 「この案を選びますか」

ラベルと値の対応を示すコロン、コードや測定値に必要な記号は残します。

### 7. 表記

同じ意味の語、敬体、句読点、日付、単位を一つの判断内でそろえます。数値は数字だけで置かず、単位と出どころを添えます。

- 不十分な例: 「保存期間を5にしますか」
- 問いにする例: 「保存期間を5日（直近30日を測った値）にしますか」

実際に測っていない数値は書きません。専門用語は初出で1行の説明を添え、略語だけを選択肢のラベルにしません。

## 判断ボード固有の規則

1. `title` は「何を決めるか」を1文で書きます。疑問文か「〜を決める」の形にし、40字以内を目安にします。
2. 選択肢は互いに排他にします。「その他」は作りません。自由記入欄がすべての判断に付くためです。
3. 「回答は不要です」または「回答不要」と書くなら、質問として出さず、よみものにします。
4. おすすめを書くときは、理由を1文で書きます。おすすめがない場合は、無理に作りません。
5. 決めないと何が起きるかを、期限または止まる作業とともに書きます。
6. 専門用語は初出で1行の説明を添えます。
7. 数字には単位と出どころ（いつ、何から測ったか）を添えます。測っていない数は書きません。
8. 1件に1つの判断だけを置きます。2つある場合は2件に分けます。

### 1件の文面の確認

- なぜ今決めるのかが、事実の範囲で分かるか。
- 選択肢を比べる材料と、選んだ後の影響が分かるか。
- おすすめと理由が混ざっていないか。ない場合に無理な推薦を足していないか。
- 決めない場合の期限または停止する作業が書かれているか。
- 自由記入で補足できるため、「その他」を選択肢にしていないか。

## 文体と構成

判断ボードは、短い敬体で書きます。説明、比較、問い、注意の働きを混ぜません。文を分けるときも、条件、因果、順序、否定、数量の範囲を保ちます。

主体や対象が元の文から分からない場合は補いません。「これ」「その案」の指す先が複数ある場合は、確認が済むまで確定しません。文末をそろえるためだけに主語を足したり、説明を「〜できます」に変えたりしません。

## 不自然な語彙・構文のカタログ

語だけで誤りと決めず、判断の内容と前後の文を確かめます。以下は候補であり、意味が同じ場合だけ使います。

| 分類 | 見直す候補 | 判断ボードでの扱い |
|---|---|---|
| 比喩動詞 | 効く、壊れる、倒す、溶かす、潰す、踏み込む、引き返す、添える、収斂する、沈黙する | 役に立つ、使えなくなる、優先する、時間がかかる、解決する、詳しく調べる、元に戻す、渡す、決まる、反応しない、など同じ幅の動詞へ。文字どおりの意味は残す |
| 英語の直訳 | 静かに壊れる、黙って無視される、〜した瞬間、正本、深掘りする、〜ではなく〜 | 気づかないうちに、知らないうちに、〜した時点で、参照元、詳しく調べる、など。唯一性や信頼性は足さない |
| 障害・失敗の比喩 | 事故、混ざる、落とし穴、破綻、実害、素通り | トラブル、入り込む、見落としやすい点、うまくいかない、実際の困りごと、気づかず通る。元の強さを保つ |
| 確認・検証の比喩 | 実測、疑う、照合、突き合わせる、断定、取り違える | 実際に測った値、念のため確かめる、照らし合わせる、見比べる、言い切る、順序を間違える、など |
| 役割・位置の比喩 | 入口、土台、道具、核心、主役、構図、線引き | はじめの一歩、基本、手段、大事な点、中心、関係、区切り。専門用語として定義済みなら残す |
| 評価・結論の定型 | 既定、別物、定番、要点、定石、桁違い | 初めの設定、まったく違うもの、よく使われるもの、大事なところ、標準の進め方、はるかに大きい、など |
| 大げさな熟語 | 真理、宿命、境地、極致、究極、虚飾、美学、深淵、冷徹、結晶 | 日常の判断に元からない大きさを足さず、事実や判断の対象を書く |
| 意味が曖昧な語 | 手触り、温度感、熱量、解像度、腹落ち、本質的、等身大、意思決定OS | 何を指すかが元の文から分かる範囲で書く。数値、原因、評価を勝手に足さない |
| 前置き・結び | 重要なのは、結論から言うと、正直に言うと、いかがでしたでしょうか、ぜひ試してください | 判断の内容を直接書く。理由、対比、依頼の働きを担う場合はその意味を残す |

「骨が折れる」「手を焼く」など定着した慣用句や、仕様上定義された語は、文字どおりの意味や必要な役割を確認してから扱います。
